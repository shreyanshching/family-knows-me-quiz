# Likely Scam 😁 - Family Quiz Website

A fun and interactive website to test how well your family members know you! Featuring an admin panel to create MCQ questions and a hilarious Matrix-style loading screen prank.

✅ **Admin Dashboard**
- Create up to 20 MCQ questions
- Add 4 options per question and mark the correct answer
- Manage (view/delete) questions
- View individual participant results
- **🏆 Live Leaderboard** with medals and rankings

✅ **Participant Quiz**
- Fun **Matrix-style "You Have Been Hacked" loading screen** (20 seconds)
- Interactive MCQ questions with progress tracking
- Instant score calculation
- Performance-based feedback messages
- View leaderboard after completing quiz

✅ **Secure Admin Access**

## 🐛 Troubleshooting

### "File cannot be accessed" error
- ✅ Make sure you **extract the ZIP file completely** to your desktop or a folder
- ✅ Don't try to open from inside the ZIP folder
- ✅ Right-click `index.html` → **Open with** → Choose your browser (Chrome, Firefox, etc.)

### Quiz won't load
- ✅ Make sure you're using a modern browser (Chrome, Firefox, Edge, Safari)
- ✅ Clear browser cache (Ctrl+Shift+Delete)
- ✅ Try a different browser

### Admin password not working
- ✅ Make sure Caps Lock is OFF
- ✅ Password is: `9026267144`

### "File not found" error
- ✅ All three files must be in the **same folder**: `index.html`, `admin.html`, `quiz.html`
- ✅ Don't move files to different folders
